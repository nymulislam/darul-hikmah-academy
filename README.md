# 📖 Darul Hikmah Islamic Academy

A modern online learning platform for learning the Quran from anywhere in the world.

---

##  Purpose
This project is designed to make Quran learning easy, accessible, and structured.  
Users can explore courses, view details, and enroll in programs with a smooth experience.

---

##  Live Site
 https://darul-hikmah-academy.vercel.app

---

##  Key Features

-  Explore and browse courses  
-  View detailed course information  
-  User authentication (Login system)  
-  Protected course details page  
-  Popular & trending courses section


---

##  Tech Stack

- Next.js  
- Tailwind CSS  
- HeroUI  
- BetterAuth
